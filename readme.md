## Selected Work

**WebScope** — Web intelligence platform for extracting and structuring dynamic web data. Clean service boundaries, failure-aware extraction logic, production deployment discipline.

**SimpUI** — UI component system built for production teams. Focused on motion, consistency, and systems-level reuse across large product surfaces.

**Signifiya** — Event operations platform for schedules, registration, and live coordination. Designed to handle peak traffic and real-time state.

**CarePulse** — Healthcare operations platform with secure workflows, provider integrations, and production-grade UX for clinics and hospitals.

**Fenix** — Real-time video platform with low-latency audio/video, secure authentication, and stable session management.

**Subscription Tracker** — Subscription management API with tracking, reminders, and cost controls. Built for predictable and auditable financial operations.
